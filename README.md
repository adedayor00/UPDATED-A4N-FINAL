# Apartments4Newark

Rooms and apartments for rent in Newark and across New Jersey, in English, Spanish and Portuguese.

- **Going live:** `SETUP.md` (Supabase database + Netlify, about 45 minutes)
- **What changed and why:** `AUDIT.md`
- **Working on the code:** `CLAUDE.md`, plus `DESIGN_SPEC.md` for the visual system

```bash
npm install
npm run dev     # demo mode: sample data, login demo@apartments4newark.com / demo1234
npm test
npm run build
```
